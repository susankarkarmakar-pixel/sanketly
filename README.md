# Sanketly

**Tagline:** The Future of Communication, Built in India. Designed for the World.

A privacy-first, end-to-end encrypted messaging app. Currently implemented: passwordless identity/auth, real-time transport, E2E encryption via `@wireapp/proteus`, group messaging, and TTL-based offline queueing.

## Build Approach

Solo dev + Google Jules (async AI coding agent), developed on GitHub.
